# Backup plan if the venue fails

Related: [[demo-script]], [[human-todo]] (section E), [[current-work]].

1. **Internet down:** switch both phones to a hotspot (practice this once). Supabase needs a connection to write.
2. **Still no connection:** show the saved data (reads work offline) and narrate the offline behavior as the feature it is.
3. **App crash or sign-in trouble:** play the screen recording of the full 7-minute run (laptop and a phone).
4. **Phone dies:** no power at preliminaries, so charge to 100% and bring a second device signed in.
5. **Demo trip data wrong:** re-run the demo seed on the test project ahead of time (README → Demo mode); never on real data.

Device limit: three at most (two phones and a laptop). No QR codes or links for judges.
